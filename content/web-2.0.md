### Mash-up 서비스 사례

- <http://www.flashearth.com/> 구글, MS, Yahoo 등의 지도 서비스를 한곳에서
- : 구글맵과 이베이의 자동차 카테고리 상품을 조합. 사용자의 위치에 가장 근접한 중고차 판매자를 찾아내는 일을 수행. 서버에는 아무런 데이터가 없음.
- <http://www.trulia.com/> : 구글 맵위에 부동산 정보를 뿌려 사용자가 지도를 이용해 편리하게 부동산 정보를 검색
- <http://zillow.com/> : MS의 버추얼 어스(Virtual Earth) OpenAPI 사용, 매물로 나온 부동산의 실제 사진을 원하는 방향에서 볼 수 있음.
- : 지도 위에 기상정보와 해당 지역의 실시간 날씨 사진, 교통 상황 정보 등을 표시
- : 이벤트 정보를 서비스하고 있는 eventfu()의 OpenAPI와 아티스트의 데이터를 연결하여 전 세계의 콘서트 정보를 확인할 수 있는 사이트.
- <http://simplyhired.com/> : 회사위치(구글맵), 인맥정보(Linkedln), 해당 직업의 연봉정보(payscale), 회사정보(zoominfo)를 같이 보여줌.

- : 토론토의 고속도로 정보
- <http://www.beerhunter.ca/> : 토론토, 리오의 술집 정보
- : 구글지도와 야후지도 + 기업AS센터 정보
- <http://labs.systemone.at/retrievr/> : 사용자가 그린 그림과 비슷한 이미지를 플릭커에서 찾아줌

- : 뉴스와 관련된 이미지를 보여줌
